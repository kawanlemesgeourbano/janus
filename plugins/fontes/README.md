# Fontes

Plugin opcional do Janus para trocar a tipografia da interface, independente do projeto ativo.

1. Atualize o Janus e abra **Plugins+**.
2. No item **Fontes**, clique em **Baixar**.
3. Abra **Configurações → Fontes**.
4. Em **Fonte título**, **Fonte subtítulo** ou **Fonte para texto corrido**, clique em **Selecionar arquivo**.
5. Escolha um arquivo **TTF, OTF, WOFF ou WOFF2**, até **10 MB**. A mudança é aplicada e salva imediatamente.

**Restaurar padrão** volta à Segoe UI naquele papel. **Desativar** volta aos padrões, preservando suas escolhas para reativação. **Remover** exclui as fontes deste plugin.

Os arquivos são copiados para os dados locais do Janus. Não é necessário instalar a fonte no Windows nem ter acesso de administrador. Logos e outros desenhos permanecem como imagens. Use fontes cujo uso você tenha autorizado; o plugin não redistribui os arquivos selecionados.
